# Chinese-Specific Glossary — okx-dapp-discovery

Use this reference only for non-literal Chinese aliases, crypto slang, and phrases whose routing meaning is not obvious from direct translation. Do not use it for ordinary Chinese words such as buy, sell, swap, stake, borrow, compare, or predict.

Normalize the matched phrase below, then apply the top-level routing rules. This glossary does not select or install a plugin by itself.
