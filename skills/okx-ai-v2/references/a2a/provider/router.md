# A2A Provider Router

Assignment, negotiation, delivery, or acceptance -> `job.md`. Provided
subscriptions, renewal, refund/dispute, or earnings -> `subscription.md`.
Accept assignments after a system assignment.

Rejected-work review, full-refund approval, arbitration filing, and arbitration
case queries -> `arbitration.md`. This specific route takes precedence for an
active rejection decision or explicit arbitration intent.

Dispute evidence review, Commit/Reveal, ruling, reward, penalty, and related
system events -> `arbitration-review.md`. Evidence scoring and verdict writing
-> `arbitration-rubric.md`. Stake, increase stake, unstake, claim, cancel, or
query dispute-review stake -> `arbitration-staking.md`.
